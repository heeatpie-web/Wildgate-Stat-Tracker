# OCR Corpus

This folder is the source of truth for OCR quality evaluation.

## Files

- `ground-truth.json`: manually corrected labels for each sample
- `predictions.latest.json`: most recent OCR run output (generated by your pipeline)
- `baseline.json`: frozen metrics from a known-good run
- `reports/latest.json`: latest evaluation report (overwritten each run)
- `reports/history/*.json`: timestamped immutable run history
- `reports/index.json`: trend index for recent runs (keeps most recent 200)

## Ground Truth Schema

Each sample is keyed by `sampleId` and should point to an image file plus expected fields.

```json
{
  "version": 1,
  "samples": [
    {
      "sampleId": "capture_2026-02-04T08-20-08-907Z",
      "imagePath": "dataset/images/train/capture_2026-02-04T08-20-08-907Z.png",
      "teammates": ["AlixThus", "Charlie"],
      "opponentTeams": [
        {
          "teamName": "MURDER SPAGHURDER",
          "teamColor": "Purple",
          "players": ["NightmareGMC", "SHTER"]
        }
      ],
      "modifiers": ["Void Storm", "Ion Squall"]
    }
  ]
}
```

## Ground Truth Without JSON

If editing JSON is a pain, use the plain-text input file:

- `dataset/ocr-corpus/ground-truth.input.txt`

Format per sample:

```text
sampleId: sample_001
imagePath: dataset/images/val/capture_001.png
teammates: TeammateA, TeammateB
opponentTeams: Team One: Enemy1, Enemy2; Team Two: Enemy3
Optional team color syntax:

```text
opponentTeams: Team One [Purple]: Enemy1, Enemy2; Team Two [Green]: Enemy3
```

modifiers: Void Storm, Ion Squall
---
sampleId: sample_002
...
```

Then build JSON automatically:

```bash
npm run ocr:truth:build
```

To add a single sample interactively (no manual formatting):

```bash
npm run ocr:truth:add
```

The wizard asks for sample id, image path, teammates, opponent teams (with optional team color), and modifiers,
shows a preview, then appends to `ground-truth.input.txt` after confirmation.

To list current sample ids and image paths:

```bash
npm run ocr:truth:list
```

To validate input before building JSON:

```bash
npm run ocr:truth:validate
```

Validation checks:
- required fields (`sampleId`, `imagePath`)
- duplicate `sampleId`
- malformed `opponentTeams` segments
- malformed optional color brackets in `opponentTeams`
- unknown keys and missing values

By default, if `ground-truth.json` already exists, the builder creates a timestamped backup:

- `dataset/ocr-corpus/ground-truth.json.bak.<timestamp>`

Custom files:

```bash
node scripts/ocr_corpus_from_text.cjs --in dataset/ocr-corpus/ground-truth.input.txt --out dataset/ocr-corpus/ground-truth.json
```

Wizard dry run:

```bash
node scripts/ocr_corpus_add_sample.cjs --input dataset/ocr-corpus/ground-truth.input.txt --dry-run
```

## Predictions Schema

Use the same `sampleId` values from `ground-truth.json`.

```json
{
  "version": 1,
  "generatedAt": "2026-02-12T00:00:00.000Z",
  "samples": [
    {
      "sampleId": "capture_2026-02-04T08-20-08-907Z",
      "teammates": ["AlixThus", "Char1ie"],
      "opponentTeams": [
        {
          "teamName": "MURDER SPAGHURDER",
          "teamColor": "Purple",
          "players": ["NightmareGMC", "SHTER"]
        }
      ],
      "modifiers": ["Void Storm", "Ion Squall"]
    }
  ]
}
```

Generate predictions from the OCR pipeline:

```bash
npm run ocr:predict
```

Custom invocation:

```bash
electron scripts/ocr_corpus_predict.cjs --truth dataset/ocr-corpus/ground-truth.json --out dataset/ocr-corpus/predictions.latest.json --ocr-mode both
```

Notes:
- The runner reads `imagePath` from each truth sample.
- Missing image files are reported and skipped.
- Use `--strict` to fail when any sample cannot be processed.

## Evaluate

Run:

```bash
npm run ocr:eval
```

Each run now writes all of:

- `dataset/ocr-corpus/reports/latest.json`
- `dataset/ocr-corpus/reports/history/<timestamp>.json`
- `dataset/ocr-corpus/reports/index.json`

With custom files:

```bash
node scripts/ocr_corpus_eval.cjs --truth dataset/ocr-corpus/ground-truth.json --pred dataset/ocr-corpus/predictions.latest.json --baseline dataset/ocr-corpus/baseline.json --out dataset/ocr-corpus/reports/latest.json
```

## Session-Usable Pass Rule

A sample passes when:

- teammate recall >= 0.67
- opponent player recall >= 0.67
- if truth has opponents, prediction must include at least one opponent player

This is intentionally practical: "good enough to prefill and save with minimal edits."

Additional metric:

- team color accuracy (for truth teams that include `teamColor` and have matching player grouping)
